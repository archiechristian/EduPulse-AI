# EduPulse AI

An AI-powered student performance intelligence platform for schools, colleges and coaching institutes.

**Student Data → AI Analysis → Identify Problems → Recommend Actions → Track Improvement**

| Layer | Tech |
| --- | --- |
| Frontend | Next.js 14 (App Router) · React · TypeScript · Tailwind CSS · GSAP ScrollTrigger · Lenis · Recharts |
| Backend | FastAPI · SQLAlchemy 2 · JWT auth (bcrypt) · SMTP email |
| Database | SQLite for local development, **Supabase Postgres** in production (`DATABASE_URL`) |
| ML | scikit-learn gradient-boosted trees (score regression + failure-risk classification) |
| LLM (optional) | Gemini or OpenAI for AI-written reports, study tips and the conversational teacher assistant |

## Quick start

### 1. Backend (http://localhost:8000)

```bash
cd backend
python -m venv .venv
.venv\Scripts\activate          # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env          # macOS/Linux: cp .env.example .env
uvicorn app.main:app --reload --port 8000
```

On first start the database is created, **seeded with demo data** (3 classes, 66 students, 5 subjects × 4 topics, 4 exams,
~80 days of attendance, homework) and the ML models are trained. API docs: http://localhost:8000/docs

Reseed at any time with `python -m app.seed --reset`.

### 2. Frontend (http://localhost:3000)

```bash
cd frontend
npm install
copy .env.local.example .env.local
npm run dev
```

## Features

**Authentication & email**
- Role-tabbed login and signup (Admin / Teacher / Student / Parent). Logging in through the wrong portal is rejected.
- Signup links records automatically: students and teachers are matched to existing records by email; parents link to
  their child by student email or roll number (more children can be linked later).
- Emails: welcome mail on signup (and with a temporary password when an admin creates an account), new sign-in alerts,
  password reset links, and early-warning alerts to parents/students.
- Without SMTP configured, emails are saved to `backend/outbox/` and shown in **Admin → Email outbox**. Set `SMTP_*` in
  `backend/.env` to send real mail (for Gmail use an App Password).

**Portals**
- **Admin** – institution overview, analytics (trends, rankings, distributions), AI Center (model metrics, feature
  importance, retrain, early-warning run), and full add/edit/delete for students, teachers, classes, subjects, topics,
  exams, assignments, grading systems, user accounts and alerts.
- **Teacher** – topic-wise marks entry, daily attendance, homework + submission grading, remarks, AI insights
  (risk table with reasons, class trend, rankings) and the **AI Teacher Assistant**.
- **Student** – performance, growth timeline, subject radar vs class, weak subjects/topics, attendance analysis,
  homework, personalised weekly **study plan** and printable **AI report**.
- **Parent** – the same insights for each linked child, plus alerts.

**AI / ML** (`backend/app/ml/`)
- `model.py` – `GradientBoostingRegressor` predicts the next exam score, `GradientBoostingClassifier` predicts failure
  (< 40%). Trained on each student's history before their latest exam (weighted ×3) plus a synthetic prior so predictions
  are sensible from day one. Swap in XGBoost by replacing the estimator classes.
- `features.py` – average, latest score, trend slope, attendance rate, homework completion/quality, failing subjects,
  consistency.
- `insights.py` – explainable risk reasons, weak-topic detection, attendance patterns (drops, streaks, weekday
  clustering), study-plan scheduling, AI reports and teacher interventions. Each works rule-based; with
  `LLM_PROVIDER=gemini|openai` and an API key, text is generated by the LLM instead.

**Landing page animation** (`frontend/components/landing/`)
- Lenis smooth scrolling driven by GSAP's ticker.
- **Pinned image-sequence scrubbing**: `ScrollSequence.tsx` pins a full-screen `<canvas>` and scrubs 180 frames with
  scroll. Frames are rendered procedurally (a student-data globe that explodes apart and reassembles into a dashboard).
  To use pre-rendered frames like Apple does, pass `frameSrc={(i) => \`/sequence/${String(i).padStart(4, "0")}.webp\`}`
  and put the images in `frontend/public/sequence/`.
- A pinned **horizontal pipeline** section, parallax layers (`data-speed`), a 3D tilt-up dashboard reveal, staggered
  scroll-triggered reveals and counters. All motion is disabled under `prefers-reduced-motion`.

## Using Supabase

1. Create a Supabase project and copy the Postgres connection string (Project Settings → Database).
2. In `backend/.env` set
   `DATABASE_URL=postgresql+psycopg2://postgres.<ref>:<password>@aws-0-<region>.pooler.supabase.com:6543/postgres`
3. Start the API: tables are created automatically (or run `supabase/schema.sql` in the SQL editor first).
   RLS is enabled on every table so they aren't exposed through Supabase's public REST API; the FastAPI backend
   enforces role-based access.

Regenerate the SQL after changing models: `python scripts/export_schema.py`.

## Production notes
- Change `JWT_SECRET`, set `SEED_DEMO_DATA=false`, and set `FRONTEND_URL` to your deployed frontend (used for CORS and
  email links).
- Tokens are stored in `localStorage`; for higher security move them to httpOnly cookies.
